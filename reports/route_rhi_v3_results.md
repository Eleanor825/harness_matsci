# Route-RHI v3 Results

## Scope

This report records the current offline experiment before the trajectory-
feedback proposer was added to `harness_matsci`. It evaluates a route-aware
uncertainty layer on three reconstructed materials-discovery tasks:

| Task | Decision target | Records | Positive | Negative |
| --- | --- | ---: | ---: | ---: |
| Pairwise optimization | Is candidate A better than B? | 2,730 | 273 | 2,457 |
| Unique-material discovery | Is this candidate worth pursuing for novelty? | 10,987 | 1,099 | 9,888 |
| Extreme-property discovery | Is this candidate worth pursuing for an extreme property? | 2,000 | 313 | 1,687 |
| **Combined** | Shared offline action benchmark | **15,717** | **1,685** | **14,032** |

The combined split contains 7,020 train, 1,414 validation, and 7,283 test
records. The task-specific splits are inherited from the original run and are
not directly comparable in sample count.

raw route accuracy because the `experiment` route dominates the proxy labels.

## Interpretation

- The combined run demonstrates that one route-aware layer can be trained on
  all three task families, but it does not establish cross-task scientific
  generalization.
- Pairwise optimization has weak calibration and almost no accepted-action
  coverage under the selected threshold.
- Unique-material discovery has a relatively strong balanced route accuracy,
  but high ECE and a high confidently-wrong rate.
- Extreme-property discovery almost completely abstains. Its aggregate route
  accuracy is therefore misleading and cannot be treated as a successful
  discovery policy.

## What this result does and does not show

It shows that the previous route-aware offline pipeline can fit, compare, and
accept/reject harness revisions on held-out `ActionRecord` groups. It does not
show that the harness improves real MatBot action utility, that it beats a
strong uncertainty baseline, or that the weak route proxies are expert labels.

The next paper-grade evaluation should run the new `rhi` command with:

1. separate-task experiments;
2. leave-one-task-out transfer;
3. five independent seeds;
4. static, verbal-confidence, heuristic, and non-RHI baselines;
5. risk-coverage curves and cost-weighted discovery utility;
6. online MatBot action-boundary logs with future utility or expert labels.

## Provenance

The original data were reconstructed from the public preferential Bayesian
optimization, DiSCoVeR/Materials Project, and RL-CC extreme-property sources.
The exact machine-readable summaries remain in the prior working tree under
`outputs/route_rhi_harness_v3/`; this tracked report intentionally records the
numbers and caveats without adding generated output trees to the repository.
